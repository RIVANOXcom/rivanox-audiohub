# Contributing

Thank you for your interest in AudioHub.

**Project language is English only.** This includes issues, pull requests, comments and documentation. The app itself is translated into five languages.

Please open an issue before undertaking substantial changes. Include Raspberry Pi model, operating-system version, connected audio devices, reproduction steps and logs with device addresses, tokens and passwords redacted.

Pull requests should be small, tested, and include source and license attribution for every new dependency. Security issues must be reported privately via [SECURITY.md](SECURITY.md).
