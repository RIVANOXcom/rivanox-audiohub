Understand your Pi4 first boot

Open the AUDIOHUB-TEST-REPORT.json file from the boot partition of a safely powered-off Raspberry Pi SD card. No connection or Python installation required.

Private by design

This viewer is self-contained. It never uploads, saves or sends the selected report; only a fixed anonymous summary appears on screen. A boot report is not ownership, hardware or release approval.

Before any physical Pi4 test

  1. Back up the untouched original SD and ALL WAV/EQ/MP3/FLAC files. Flash a disposable spare SD only with explicit approval.
  2. STOP unless the operator has approved a safe Pi4 shutdown method BEFORE booting. No SSH, shared passwords or trusted home network.
  3. Verify the downloaded ZIP SHA256 and inner IMG.XZ/manifest/viewer checksums independently before extraction or flashing. This viewer never verifies the ZIP.
